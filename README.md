# Ha Phung Hao — Portfolio Website (flat structure, single index.html)

## Cách upload lại cho đúng (làm theo đúng thứ tự để tránh lặp lỗi cũ)

1. Vào repo `phung-hao/portfolio` trên GitHub.
2. Chọn **hết tất cả file hiện có** trong repo (tick chọn từng file hoặc dùng "..." → Delete) và xóa sạch, để repo trống hoàn toàn. (Có thể giữ lại README cũ hoặc xóa luôn cũng được.)
3. Vào lại repo, bấm **Add file → Upload files**.
4. Mở thư mục chứa 10 file này trên máy bạn, **bấm Ctrl+A để chọn tất cả 10 file cùng lúc**, rồi kéo thả cả cụm vào khung upload của GitHub trong MỘT LẦN (không kéo từng file một, để tránh bị lệch/đè nhầm nội dung như 2 lần trước).
5. Đợi tất cả 10 file hiện lên trong khung xác nhận, kiểm tra đủ tên:
   - `index.html`
   - `hero_bg.jpg`
   - `exp1.jpg`, `exp2.jpg`, `exp3.jpg`
   - `logo_ongfree.jpg`, `logo_bookalens.jpg`, `logo_earlie.jpg`
   - `portrait_about.jpg`, `portrait_contact.jpg`
6. Bấm **Commit changes**.
7. Đợi khoảng 1 phút, mở `phung-hao.github.io/portfolio/` và **Ctrl+F5** để xóa cache trình duyệt.

## Vì sao lần này nên ổn
- Chỉ còn **1 file HTML duy nhất** (đã gộp sẵn CSS + JS bên trong) — không còn thư mục con nào để bị lệch cấu trúc.
- Toàn bộ ảnh đều để phẳng ngay cạnh `index.html`, đúng tên, đúng nội dung đã kiểm tra lại.
- Upload một lần duy nhất (chọn hết file rồi thả 1 lần) để tránh việc thao tác nhiều lần khiến file bị đè/nhầm tên như các lần trước.

Nếu sau bước này vẫn có ảnh sai chỗ, chụp màn hình gửi lại, mình sẽ kiểm tra tiếp.
